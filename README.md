Online Shopping Cart

Overview

This is a Python-based shopping cart application that allows users to manage items in their cart through an interactive menu system. The program demonstrates object-oriented programming concepts with two main classes and a user-friendly command-line interface.

Features

Add Items: Add items with name, description, price, and quantity
Remove Items: Remove items from the cart by name
Modify Quantities: Update item quantities using a temporary object approach
View Cart: Display shopping cart with item costs and total
View Descriptions: Display all item descriptions in the cart
Input Validation: Handles invalid entries gracefully for prices and quantities
